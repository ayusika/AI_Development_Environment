## 2026-08-09｜Writer長文Transport・セーブ経路更新

### Writer Adaptive Chunk Transport

Koppy World WriterへAdaptive Chunk Transportを統合。

通常のProposal送信がWAFによってHTTP 403となった場合、自動的にAdaptive Chunk Transportへフォールバックする構成とした。

長文をBase64へ変換して分割し、WAFを通過できないChunkのみをさらに再分割する。

全Chunk送信後はサーバー側で再結合し、SHA-256による完全性検証を行ってからProposalを生成する。

本番Koppy WorldのWriter UIから長文Proposalを作成し、DevToolsによる手動分割・送信なしで正常完走することを確認した。

### Koppy World UI Deploy

`900_Lab/Web_KoppyOS_Beta/index.html`

を

`/koppy/index.html`

へDeployするExact Match AllowlistをDeploy系APIへ追加。

Koppy World UI自身をProposal → Approval → Execute経路で本番反映できるようにした。

### 000_HOME Writer権限

以下4ファイルをWriterのExact Match Allowlistへ追加。

- `000_HOME/決定事項.md`
- `000_HOME/現在の状態.md`
- `000_HOME/更新履歴.md`
- `000_HOME/次にやること.md`

これにより「セーブ！」で使用するKoppyOS運用情報をWriter Proposal経由でGitHubへ保存できる基盤が開通した。

## 2026-08-09｜UI Deploy target表示不整合 修正

Deploy ExecutorでKoppy World UIをDeployした際、実際の配置先は `/koppy/index.html` で正常であるにもかかわらず、実行レスポンスおよびDeploy Log上の配置先が `/koppy/api/` と誤表示される不整合を修正した。

### 修正内容

`600_KoppyOS/server/api/v1/deploy/executor.php` の以下2箇所を、Deploy対象に応じて分岐するよう修正。

- Deploy Logの `target_server_path`
- 実行レスポンスの `server_target`

APIファイルの場合：

`/koppy/api/...`

Koppy World UIの場合：

`/koppy/index.html`

### 本番確認

修正版Deploy Executorを本番反映し、hash / size検証の成功を確認。

Koppy World UIについても、

`server_target: "/koppy/index.html"`

が正しく返ることを確認した。

これにより、UI Deployの実配置・Deploy Log・APIレスポンスで配置先の表現が一致した。
